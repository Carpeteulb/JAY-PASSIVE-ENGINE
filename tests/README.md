# 연봉 계산 회귀 테스트

기준: main / 8c1b85ef430b873d571cfcb3d8d0f33de4a43a5c (2026-09-20).
작업 시점 main은 이 커밋과 동일했습니다.

## 실행

Node.js 22 이상에서 저장소 루트에서 실행:

```sh
npm test
```

외부 패키지, npm install, lockfile이 필요하지 않습니다.
Node 내장 node:test, assert, vm을 사용하며 실제 app.js를 실행합니다.
프로덕션 코드와 index.html은 변경하지 않습니다.

## 범위

- 숫자 입력 정리, 빈 입력, 0, 비숫자 입력
- 공제율 10.5%, 12.5%, 14.5%, 17%, 20% 및 각 경계 ±1원
- 월급과 공제액의 순차 반올림, 실수령액, KRW 표시
- 폼 제출 시 preventDefault, 입력 서식, 빠른 선택 버튼 4개
- HTML 필수 요소 및 app.js 연결

현재 입력 규칙은 숫자 외 문자를 제거합니다. 따라서 -123은 123,
12.34는 1234로 처리됩니다. 이 테스트는 해당 기존 동작을 기록하며
음수/소수 입력을 올바르게 지원한다는 뜻은 아닙니다.
공제율은 간편 추정식의 회귀 기준이며 실제 세법 정확성을 보증하지 않습니다.
DOM 대역을 사용하므로 실제 브라우저의 레이아웃과 이벤트 전달은 검증하지 않습니다.

## CI

.github/workflows/test.yml은 main push, main 대상 PR, 수동 실행을 지원합니다.
Ubuntu / Node.js 22에서 동일한 npm test를 실행합니다.
테스트 실패 시 작업이 실패하며 contents: read 권한만 사용합니다.
수동 실행은 workflow가 기본 브랜치에 병합된 뒤 사용할 수 있습니다.
